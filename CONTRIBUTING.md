# Contributing — CineFlow Open

Terima kasih sudah mau berkontribusi!

## Alur kerja

1. **Normal flow lewat Pull Request** — branch `main` dilindungi.
2. **Satu PR, satu tujuan.**
3. **Wajib update `CHANGELOG.md`** pada perubahan kode.
4. **Jangan build lokal untuk rilis.** Rilis hanya lewat GitHub Actions.

## Aturan bahasa & gaya

- **UI aplikasi: Bahasa Indonesia.** Komentar kode: Bahasa Indonesia.
- Gaya commit: `type(scope): deskripsi` — `feat`, `fix`, `ui`, `perf`, `refactor`, `docs`, `chore`.
- Jangan ubah `versionName`/`versionCode` manual.

## Keamanan

- Jangan commit keystore (`*.jks`, `keystore.b64`).
- Jangan tempel token/secret di issue, PR, atau chat.
